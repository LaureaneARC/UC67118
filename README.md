# Arduino Projects and Hardware Assembly

This repository contains Arduino exercises and practical hardware assembly evidence completed for UC67118. The projects cover digital inputs and outputs, relay control, servo control, LCD feedback, traffic-light sequencing, temperature-based control, and electrical-panel assembly.

## Projects

### `arduino-dual-button-relay-control`

Arduino sketch for reading two push buttons and controlling a relay. The sketch also reports the button state through the Serial Monitor.

### `arduino-joystick-servo-motor`

Joystick-controlled servo motor with a 16x2 LCD. The joystick direction changes the servo angle, and the movement speed depends on how far the joystick is moved.

### `arduino-semaphore`

Traffic-light sequence using red, yellow, and green LEDs. Each light remains active for ten seconds before the next state.

### `arduino-temperature-sensor`

Temperature-sensor and relay project for switching a lamp. The folder includes the circuit image and a demonstration video.

### `electrical-panel`

Electrical-panel assembly documentation, including the assembly image, wiring/power scheme, diagram, budget spreadsheet, and demonstration video.

## Hardware and software

- Arduino-compatible board
- Breadboard and jumper wires
- LEDs and suitable resistors
- Push buttons
- Relay module
- Servo motor
- Joystick module
- 16x2 LCD
- Temperature sensor and lamp circuit
- Arduino IDE or PlatformIO
